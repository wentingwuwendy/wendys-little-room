## 房间里有什么

- 书架：小红书、京东、波士顿咨询三段实习档案。
- 电脑：欧莱雅 BRANDSTORM、新加坡管理大学 ESG 挑战赛。

- 旅行墙：东京、旧金山、洛杉矶、纽约、多伦多、圣迭戈、新加坡。
- 落地灯：昼夜切换，同步变化窗外风景、灯光和界面，自动记住偏好。

支持鼠标与触屏轻微旋转。下方导航可以访问所有内容；弹窗支持 Escape 关闭和键盘焦点管理。无法显示 WebGL 时，文字内容仍可正常访问。

## 本地预览

需要 Node.js 22 和 pnpm 10。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

构建：`pnpm build`。发布内容位于 `dist/`，Vite 使用相对路径，可放在 GitHub Pages 的仓库子路径。

## GitHub 发布

账号：`wentingwuwendy`。计划新仓库：`wendys-little-room`。

先从 https://cli.github.com/ 安装 GitHub 官方命令行工具，然后双击 `发布网站.cmd`。程序会引导一次 GitHub 网页登录，然后新建公开仓库、启用 GitHub Pages 并上传代码。首次发布后，GitHub Actions 自动完成构建和部署。

已按最新要求准备 GitHub Pages 发布；实际公开地址以 GitHub Actions 部署成功后的结果为准。

脚本会验证登录账号，若目标仓库已存在或当前目录已有其他 Git 记录则停止，避免覆盖已有项目。后续代码更新可正常提交推送，主分支会自动重新部署。
